# AI Assistant Chatbot

## Overview
This project is a simple AI-powered chatbot developed using Python and Natural Language Processing concepts. The chatbot can interact with users and respond to basic queries in real time.

## Features
- User interaction handling
- Predefined intelligent responses
- Beginner NLP implementation
- Simple and interactive interface

## Technologies Used
- Python
- NLP Concepts
- VS Code

## Purpose
This project was developed to improve problem-solving, logical thinking, and practical programming skills.
